## Welcome to RainTools

RainTools is a powerful Minecraft plugin for Spigot/Paper servers that allows you to create custom rain areas where items, experience orbs, and entities can fall. Perfect for creating unique gameplay experiences, event areas, or reward zones.

## Quick Example

Create a rain area where diamond blocks fall with 50% probability:

<Steps>
  <Step title="Select the area">
    Use WorldEdit or the built-in selection tool to mark two corners
    ```
    Left-click first corner
    Right-click second corner
    ```
  </Step>
  <Step title="Create the rain area">
    ```
    /rainarea create diamond_rain
    ```
  </Step>
  <Step title="Save the item">
    Hold a diamond block and run:
    ```
    /saveitem diamond_block
    ```
  </Step>
  <Step title="Add item to area">
    ```
    /saveitem add diamond_rain diamond_block 0.5
    ```
  </Step>
  <Step title="Start the rain">
    ```
    /rainarea start diamond_rain
    ```
  </Step>
</Steps>
